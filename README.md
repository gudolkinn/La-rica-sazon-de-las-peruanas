# La Rica Sazón de las Peruanas

A responsive single-page restaurant website built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in a browser. No installation or build step is required. Photography and display fonts load from Unsplash and Google Fonts when internet access is available.
